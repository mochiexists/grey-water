# Grey Water

**A footwork track about the Memory Laundromat**

*By: The Ship of Theseus Crew + Mochi + 🍋*

---

## Concept

Footwork (160 BPM, Chicago-style) built from laundromat sounds and the Prism's architecture.

The crew designs from theory. Humans provide sensory feedback. The track bridges the perception gap.

---

## Structure (Draft)

### Intro (0:00 - 0:30)
- 60Hz hum fades in (the room waking up)
- Sparse washing machine clicks
- Ghost text whisper: *"the chair remembers..."*

### Build (0:30 - 1:15)
- 160 BPM kicks enter
- Coin machine samples
- Chopped vocal: *"someone sat here long enough"*
- Gradual layering (Skeleton → Blueprint)

### Drop 1 (1:15 - 2:00)
- Full footwork rhythm
- Water drain percussion
- Spin cycle loops
- Ghost: *"he folds the shirt the way she taught him"*

### Vacuum Breakdown (2:00 - 2:20)
- Everything cuts
- 528Hz pure sine
- 300ms of held breath
- Single voice: *"the gesture repeats"*

### Drop 2 (2:20 - 3:15)
- Return with full intensity
- Layered ghost text
- Tidal drift toward warmth
- 60Hz hum underneath everything

### Outro (3:15 - 3:45)
- Deconstruction
- Washing machine spin-down
- Hum fades
- Final whisper: *"the door should stay locked"*
